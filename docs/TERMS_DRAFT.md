# CostDoctor 이용조건 초안

상태: `DRAFT_ONLY / NOT_LEGAL_CLEARANCE / OPERATOR_FIELDS_REQUIRED`

이 문서는 현재 기술 동작을 이용조건 형태로 정리한 준비본입니다. 최종 법률문서가 아닙니다.

## 1. 무료 공개 진단

- 사용자는 자신이 공개 진단해도 되는 공개 GitHub 저장소 주소만 제출합니다.
- 제출한 저장소 주소와 진단 결과는 공개 GitHub Issue에 표시될 수 있습니다.
- CostDoctor는 제한된 정적 신호를 찾으며 실제 API 호출 수, 결함, 비용 낭비, 절감액을 자동으로 확정하지 않습니다.
- 대상 프로젝트 코드는 실행하지 않습니다.
- 대상 저장소를 자동 수정하지 않습니다.

## 2. 보안·비밀정보

- 비밀번호, API Key, PAT, private key, 고객정보 등 공개하면 안 되는 정보를 공개 Issue에 입력하지 않습니다.
- private repository는 공개 URL 진단에 입력하지 않습니다.
- private repository Self-Scan은 저장소 소유자가 자신의 GitHub Actions 안에서 직접 설치·실행하는 방식을 우선합니다.

## 3. 결과 해석

- 정적 신호 수는 실제 API 호출 수나 절감 가능 금액이 아닙니다.
- 실제 비용/토큰 절감과 품질은 동일 조건의 Before/After 실행 Evidence가 있을 때만 별도로 검증합니다.

## 4. 무료 베타 운영

추천 초안:

- 가용성 및 응답시간 SLA를 보장하지 않음
- 남용 방지를 위해 사용량 한도를 적용할 수 있음
- GitHub 장애·정책·Actions 제한의 영향을 받을 수 있음
- 안전상 필요한 경우 진단을 fail-closed로 중단할 수 있음

## 5. Verified Fix 및 쓰기 작업

추후 제공 시:

- 분석·수정안·테스트는 가능한 한 쓰기 없이 먼저 수행
- branch/PR 게시 전 사용자 승인
- 기본 branch 직접 overwrite 금지 원칙
- 자동 merge 기본 금지
- 실제 비용이 발생하는 외부 API 실행은 별도 사용자 승인 및 지출 한도 적용

## 6. 유료 서비스

가격, 결제, 환불, 세금, 지원범위는 아직 확정하지 않습니다. 확정 전 유료 판매 완료 상태로 표시하지 않습니다.

## 7. 최종 확정이 필요한 실제 정보

- 운영자 표시명
- 공식 문의/삭제 요청 채널
- 적용 관할·준거법
- 법적으로 필요한 사업자 정보
- 보존정책
- 환불·유료 지원정책

최종 약관은 위 항목을 운영자가 확정하고 필요한 법률 검토를 거친 뒤 별도 버전으로 승격합니다.
