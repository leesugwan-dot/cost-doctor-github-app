저장소는 그대로입니다.

  • 읽기 전용 진단
  • 자동 수정·push·merge 없음

  • 외부 telemetry 기본 OFF

무엇을 받나요?

후보 수가 아니라 근거와 다음 행동을 함께 봅니다.

모델 호출실행 경로 호출 후보와 SDK import를 구분합니다.
재시도활성 증폭과 문서·테스트 신호를 구분합니다.
캐시AI 문맥 캐시와 일반 파일 캐시를 구분합니다.
토큰·문맥재현 가능한 구조적 측정값만 표시합니다.

무료 경로에는 Provider usage가 없으므로 실제 비용·절감률은 UNKNOWN으로 남을 수 있습니다. 검증된 절감은 동일 workload의 Before/After usage와 품질 Evidence가 있을 때만 표시합니다.

비공개 저장소

결과를 공개하고 싶지 않다면 내 Actions에서 실행하세요.

Private Self-Scan은 `contents: read` 범위에서 고객 runner 안에서만 동작합니다. source는 운영자 PC로 전송되지 않습니다.

Private Self-Scan 안내

CostDoctor는 Apache-2.0 공개 통합 계층입니다. 정적 신호는 Verified Savings가 아닙니다.
