# Pilot 결과 보고

외부 사용 Evidence는 성공·실패 모두 같은 형식으로 수집합니다. 저장소·사용자·코드 원문은 수집하지 않습니다.

필수 항목:

1. 설치 완료 여부와 걸린 시간 구간
2. PR event 수와 `Cost Doctor` Check 생성 여부
3. 정확한 head SHA 일치 여부(값 자체가 아니라 일치/불일치만)
4. 발견 신호 수와 사람이 확인한 유효/오탐 수
5. Check가 `success`, `neutral`, 오류 중 무엇이었는지
6. 재시도·재작업 발생 여부
7. 제거 성공 여부
8. 다시 사용할 의향: 예/아니오/미정

비용·절감 수치는 검증된 telemetry가 없는 경우 `UNKNOWN`으로 남깁니다. 토큰·secret·원문 코드·비공개 파일명·개인정보는 Issue에 넣지 않습니다.
