# CostDoctor 결제·수익화 정책 — 보류 기록

상태: `DEFERRED_UNTIL_PUBLIC_REACTION / BILLING_DISABLED`

사용자 결정에 따라 **유료화 방식·가격·환불정책은 현재 확정하지 않습니다.** 무료 공개 진단 반응과 외부 가치 Evidence를 본 뒤 다시 결정합니다.

## 현재 확정된 것

- 무료 공개 진단은 계속 무료
- 결제 기능은 활성화하지 않음
- 정적 신호만으로 유료 절감효과를 주장하지 않음
- 실제 API 측정이 필요한 미래 기능은 고객 자신의 Provider 계정과 GitHub Secret을 사용
- 실제 API 실행 전 작업별 최대 지출한도 승인을 요구
- 승인 한도 초과 가능 시 fail-closed

## 향후 다시 검토할 후보

외부 반응이 충분히 쌓인 뒤 다음을 비교합니다.

- Verified Fix 건별 과금
- 월 구독/팀 플랜
- 반복 모니터링
- 무료 사용 한도
- 환불/지원 범위

현재는 어느 방식도 실제 가격정책으로 승격하지 않습니다.
