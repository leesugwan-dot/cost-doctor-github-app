# CostDoctor 무료 공개 진단 FAQ

## 설치해야 하나요?
아니요. 공개 저장소 진단은 링크를 열고 GitHub 저장소 주소를 붙여넣은 뒤 제출하면 됩니다.

## 내 PC에 프로그램이 설치되나요?
아니요. 공개 진단은 사용자의 PC와 CostDoctor 운영자의 개인 PC를 사용하지 않습니다.

## private repository도 되나요?
현재 무료 공개 진단은 지원하지 않습니다. private repository는 별도 GitHub 권한 승인 구조가 필요합니다.

## 내 코드를 실행하나요?
아니요. 제한된 정적 텍스트 분석만 수행합니다.

## 내 저장소를 수정하나요?
아니요. commit, push, PR 생성, 파일 수정 같은 쓰기 작업을 하지 않습니다.

## 결과가 공개되나요?
네. 현재 무료 베타 요청과 결과는 CostDoctor 공개 GitHub Issue에 표시됩니다. 공개하면 안 되는 정보는 입력하지 마세요.

## 결과의 숫자가 실제 API 호출 수인가요?
아니요. 정적 코드에서 찾은 검토 신호 수입니다. 주석, 예제, 테스트도 포함될 수 있습니다.

## 비용 절감이 확인됐다는 뜻인가요?
아니요. 실제 비용·토큰 절감은 `UNKNOWN`입니다. 실제 Before/After 실행과 품질 검증이 있어야 절감을 증명할 수 있습니다.

## 왜 사용자당 24시간 5회 제한이 있나요?
무료 공개 서비스를 자동 남용이나 반복 요청으로부터 보호하고 다른 사용자가 함께 사용할 수 있게 하기 위한 베타 한도입니다.

## GitHub 파일이나 branch 링크를 넣어도 되나요?
네. 같은 저장소의 `tree`, `blob` 등 GitHub 내부 링크를 붙여넣어도 저장소 기준으로 자동 정리합니다.

## 분석하는 동안 저장소가 바뀌면 어떻게 되나요?
분석 직전 GitHub API에서 확인한 기본 브랜치 HEAD와 실제 checkout HEAD가 다르면 중단하고 새 요청을 안내합니다.

## 결과가 실패하면 저장소가 망가지나요?
아니요. 대상 저장소에는 쓰지 않기 때문에 rollback할 변경 자체가 없습니다.

## API Key나 결제가 필요한가요?
현재 공개 정적 진단에는 필요하지 않습니다.

## 한국어만 지원하나요?
아니요. 현재 결과는 한국어와 English를 선택할 수 있습니다.
